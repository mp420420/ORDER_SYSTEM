# 線上點餐系統

公司內部訂飲料用的網頁工具，支援 **甘丹茶飲 / 50嵐 / 鮮茶道** 三家店。

👉 **使用網址：** https://mp420420.github.io/ORDER_SYSTEM/

---

## 三個分頁

| 分頁 | 用途 |
|---|---|
| **點餐** | 挑飲料、選規格與加料、填客人需求，加入清單後送出 |
| **訂單** | 看目前這家店的所有訂單、複製叫餐清單 |
| **後台** | 統計金額、收款登記、菜單管理、截止點餐、匯出報表 |

## 同事怎麼用

1. 上方選店家（**綠點**＝開放中，**紅點加刪除線**＝已截止）
2. 點飲料 → 選容量、甜度、冰塊、加料，有特殊需求填在「客人需求」
3. 加入清單，同款可用 **+ / −** 調整杯數
4. 填**姓名/分機**與**自訂 4 位數密碼**（要刪自己的訂單時會用到，請記住）
5. 送出

> 購物車不能跨店，切換店家會提示並清空。

## 主揪功能（後台）

- **收款狀況** — 依人列出杯數與金額，收到錢就打勾，已收/未收即時統計
- **菜單管理** — 線上改價格、改品名、新增或停售品項、調整加料
- **點餐開放/截止** — 每家店各自控制，截止後同事就送不出該店訂單
- **複製叫餐清單** — 兩種格式切換：
  - 點餐分類（叫餐用）：相同品項合併計數
  - 人名顯示（發飲料用）：`分機/品項(加料、需求)/甜度/冰塊/杯型/$金額`
- **匯出 Excel** — CSV 報表
- **清除訂單（開新團）** — 清空該店訂單與收款紀錄

以上功能都需要主揪密碼。

## 技術架構

- 前端：單一 `index.html`（Tailwind CSS，無需建置）
- 後端：Google Apps Script Web App
- 資料庫：Google 試算表

試算表分頁：各店訂單、`菜單`、`加料`、`點餐狀態`、`收款`

菜單讀不到時會自動改用程式內建的備援菜單，不會出現空白菜單。
